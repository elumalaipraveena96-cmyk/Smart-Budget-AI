# Smart Budget AI

A simple monthly budget and expense tracking website.

## Features
- Set Monthly Budget
- Add Daily Expenses
- View Expense History
- Edit and Delete Expenses
- Pie Chart for Category Analysis
- AI Saving Suggestions
- Automatic Balance Calculation

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## How to Use
1. Open the website.
2. Set your monthly budget.
3. Add your expenses.
4. View your expense history and pie chart.
5. Get saving suggestions.
